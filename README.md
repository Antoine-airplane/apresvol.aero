# chocksoff.aero

Site de présentation de **Chocks Off**, l'app iOS qui enregistre les vols VFR automatiquement à partir du GPS.

- `index.html` : page d'accueil (FR / EN)
- `privacy/` : politique de confidentialité (source : `docs/privacy/index.html` du dépôt de l'app)

Publié par GitHub Pages depuis `main`. Domaine `chocksoff.aero` à brancher (fichier `CNAME` + DNS) quand le domaine est enregistré.
