# apresvol.aero

Site de présentation de **Après-Vol**, l'app iOS qui enregistre les vols VFR automatiquement à partir du GPS.

- `index.html` : page d'accueil (FR / EN)
- `privacy/` : politique de confidentialité, **copie** de `docs/privacy/index.html` du dépôt de l'app : la modifier là-bas, puis la recopier ici (l'App Store pointe vers https://apresvol.aero/privacy/).

Soutenir le projet : https://buymeacoffee.com/apresvol

Publié par GitHub Pages depuis `main`. Domaine : https://apresvol.aero (fichier `CNAME`, DNS chez Infomaniak : 4 A GitHub Pages + CNAME www).

Tout push sur `main` est publié aussitôt.
